ARAB PERMISSION STRUCTURE IMPLEMENTED

Admin: Games FULL; Game Assignment FULL; Game Reports FULL.
Referee: Games VIEW ONLY; Game Assignment VIEW ONLY; Game Reports NO ACCESS.
Official: Games ASSIGNED GAMES; Game Assignment = SUBMIT/VIEW REPORT for assigned games; Game Reports FULL.
TO: Games ASSIGNED GAMES; Game Assignment = SUBMIT/VIEW REPORT for assigned games; Game Reports ASSIGNED GAMES/REPORTS.
Finance: Games VIEW ONLY; Game Assignment VIEW ONLY; Game Reports VIEW/REPORT ACCESS.

Official/TO cannot assign or reassign officials. Only Admin can assign/reassign.
Official/TO report submission does not modify existing official assignments.
Finance cannot submit/upload reports. Referee cannot access Game Reports.
